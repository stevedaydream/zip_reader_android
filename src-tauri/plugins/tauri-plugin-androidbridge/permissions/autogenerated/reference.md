## Default Permission

Default permissions: TTS speak/stop and all-files-access helpers

#### This default permission set includes the following:

- `allow-speak`
- `allow-stopSpeak`
- `allow-endTts`
- `allow-updatePlayback`
- `allow-listVoices`
- `allow-listEngines`
- `allow-setEngine`
- `allow-hasAllFilesAccess`
- `allow-requestAllFilesAccess`
- `allow-pickFolder`
- `allow-registerListener`
- `allow-removeListener`
